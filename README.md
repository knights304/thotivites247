# Thotivites247 Web

Static Cloudflare Pages site for shared Thotivities spin links.

## Example share URL

https://thotivites247.pages.dev/spin.html?symbol=🔥&title=Dance%20Challenge&category=DANCE%20CHALLENGE&rating=10

## Push to GitHub

```bash
cd ~/Downloads/thotivites247_web
git init
git branch -M main
git remote add origin https://github.com/knights304/thotivites247.git
git add .
git commit -m "Add Thotivites247 share site"
git push -u origin main
```
